Create security group

September 11, 2024 AWSBlogLab 2 min

SG cho public subnet¶

Đầu tiên chọn mục security group trong VPC Dashboard và chọn tạo security group

Chọn VPC cho Security group cần tạo

Thiết lập những kết nối từ bên ngoài có thể truy cập vào trong public subnet với security group:

  • SSH: cho phép kết nối ssh vào trong các public subnet điều này đồng nghĩa các tài nguyên chẳng hạn như máy chủ EC2 được cài đặt trong public subnet có thể truy cập từ mọi địa chỉ IPv4.
  • Custom ICMP - IPv4 cho phép ping tới server trong public subnet

Đối với outbound thì cho phép các tài nguyên trong public subnet có thể kết nối với internet.

Cuối cùng hoàn tất việc tạo security group

SG cho private subnet¶

Tương tự với việc tạo public subnet cần thiết lập tên, mô tả và VPC mà security group gắn liền

Với inbound rule cho phép các tài nguyền nằm trong miền CIDR của public security group có thể SSH tới tài nguyên trong private subnet
Chẳng hạn cho phép public subnet có máy chủ EC2 từ public subnet được kết nối SSH với máy chủ EC2 trong private subnet

Tiếp đó thêm inbound rule để cho phép ping tới các tài nguyên trong private subnet cho mọi địa chỉ IPv4

Về outbound rule không có hạn chế nào đối với các tài nguyên trong private subnet
