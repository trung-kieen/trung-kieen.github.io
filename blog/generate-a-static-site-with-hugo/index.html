Get started with hugo

September 4, 2024 2 min

For getting with writing a blog we can use Hugo to generate a static site.I look over some themes and i found that doks theme look pretty good.

First we need to install Hugo
The doks theme installation is a little difference with other themes. We need npm to install this package

1

npm create thulite@latest --template doks

I name my project as my-blog

my-blogs/ folder we create form this command not treat as hugo theme folder but actually create a premade hugo project for us. So we don’t need to run this command to create hugo project

1

hugo new site <project-name>

We navigate to our new project folder

1

cd my-blog

Now we can use this project to render static site

1

hugo server

Open default host http://localhost:1313/ in browser
Aw it look pretty good right

Let try to write some new posts for our blog. We need to create new markdown file from hugo command

1

hugo new blog/hugo-guide/index.md


Our post content is store at file blog/hugo-guide/index.md

Hugo file structure is intuitive when create from hugo command. Basically the beginning section generate from template for us
When leave draft value to true it mean hugo we not render this file to public/ folder. So we when everything done we will set it into false

Now we change draft to false to render this post

Now let open browser to take a look

Let see our post content

Okay that all we need to setup a basic blog with hugo.

Publish to github page¶

In previous section we able to run a site from markdown note in our local machine. How do we generate a public page with hugo?

Let run command that generated static resource from markdown note to public/ folder

1

hugo


Now public folder have all we need to public a website

Let create a github repository with .github.io as repository name suffix.

Mark this folder as sub repository for better management

1

git

Make folder public as a new repository

1
2
3
4

cd public/
git init . 
git commit -m "Initial commit"
git branch -M main

Now we need to make this public/ folder direct content this repo

1
2

git remote add origin git@github.com:<username>/<repo_name>.github.io.git
git push origin main
